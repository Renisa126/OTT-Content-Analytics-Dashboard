# OTT-Content-Analytics-Dashboard
Interactive Power BI dashboard analyzing OTT movies and web series by platform, genre, country, release year, and IMDb ratings using KPI cards, charts, and filters.

# 📊 OTT Content Analytics Dashboard

## 📌 Project Overview
The OTT Content Analytics Dashboard is a data visualization project developed using Microsoft Power BI. It analyzes movies and web series available across different OTT platforms and presents insights through interactive charts, graphs, KPI cards, and filters.

## 🎯 Project Objectives
- Analyze movies and web series.
- Compare content across OTT platforms.
- Explore genres and countries of production.
- Analyze content release trends over the years.
- Identify highly rated titles using IMDb ratings.
- Present insights through an interactive dashboard.

## 🛠️ Tools and Technologies
- **Microsoft Power BI** — Dashboard creation and data visualization.
- **Microsoft Excel** — Dataset preparation and data source.

## 📂 Dataset Details
The dataset contains the following information:
- Title
- Content Type (Movie or Series)
- OTT Platform
- Genre
- Country
- Release Year
- Seasons
- Content Rating
- IMDb Rating
- Episodes/Duration

## 📈 Dashboard Features

### KPI Cards
- Total Titles
- Total Movies
- Total Series
- Average IMDb Rating

### Visualizations
- Movies vs. Series
- Content by OTT Platform
- Content by Genre
- Content by Country
- Content Released by Year
- Top-Rated Titles

### Interactive Filters
- Platform
- Content Type
- Release Year

## ⚙️ Project Workflow
1. Imported the Excel dataset into Power BI.
2. Loaded the `OTT_Data` table.
3. Created KPI cards to summarize the data.
4. Designed charts to analyze content across different categories.
5. Added slicers to filter the dashboard interactively.
6. Designed the final dashboard for clear and easy data exploration.

## 💡 Key Benefits
- Simplifies OTT content analysis.
- Helps identify trends and patterns.
- Enables comparisons between platforms and genres.
- Provides an interactive way to explore data.

## 🖥️ How to View the Project
1. Download the `.pbix` dashboard file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the charts, KPI cards, and interactive filters.
